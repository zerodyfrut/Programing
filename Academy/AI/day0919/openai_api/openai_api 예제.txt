OpenAI API 

OpenAI API: 모델에 요청(request)을 보내고, 결과(response)를 받는 구조.

주요 용어:

Model: GPT, Whisper 등 다양한 모델. 예: gpt-4, gpt-3.5-turbo.
Prompt: 모델에게 전달하는 입력 텍스트.
Response: 모델이 반환하는 결과.
API Key: 인증용 키. OpenAI 계정에서 발급.

동작 방식 예시:
사용자 입력 → API 요청 → OpenAI 모델 처리 → 결과 반환

#pip install openai
from openai import OpenAI
import os

api_key = "키 입력"



# API 키 설정 (환경 변수 사용 권장)
client = OpenAI(api_key=api_key)

def chat_with_gpt(messages):
    response = client.chat.completions.create(
        model="gpt-3.5-turbo",
        messages=messages,
        temperature=0.7  # 창의성 조절
    )
    return response.choices[0].message.content

def main():
    print("=== 미니 챗봇 시작 ===")
    messages = [{"role": "system", "content": "You are a helpful assistant."}]

    while True:
        user_input = input("You: ")
        if user_input.lower() in ["exit", "quit"]:
            print("챗봇 종료!")
            break

        messages.append({"role": "user", "content": user_input})
        bot_reply = chat_with_gpt(messages)
        messages.append({"role": "assistant", "content": bot_reply})

        print("Bot:", bot_reply)


if __name__ == "__main__":
    main()
------------------------------------------------------------------------------------

messages 리스트를 유지해서 대화 문맥을 기억하게 함
system 메시지는 챗봇 성격 지정
temperature로 답변의 창의성 조절
exit 또는 quit 입력 시 종료



****RAG (Retrieval-Augmented Generation)****

데이터를 따로 저장(DB(벡터DB 데이터를 숫자로 저장하는 DB로 우리가 아는 DB랑 다름), 벡터 스토어) 
→ 질문이 들어올 때 검색 후 결과를 프롬프트에 추가

대규모 자료를 다룰 때 제일 많이 쓰는 방식

도서관식 구조:
1. PDF/DB 등에서 문장을 추출 → 임베딩 저장
2. 사용자가 질문 → 검색 → 관련 문단만 모델에 전달

Python 생태계: langchain, llama-index 등


** 전체 흐름 **

1. 문서 → 텍스트 추출
PDF, Word, Excel 등에서 텍스트를 뽑습니다.
Python 도구: pypdf, python-docx, openpyxl 등.

2. 텍스트 → 조각(chunking)
문단/섹션 단위로 잘라야 검색 품질이 올라갑니다.
예: 300~500자 단위로 분리.

3. 조각 → 임베딩 생성 & 저장
OpenAI의 text-embedding-3-small 모델을 이용해 벡터를 만듭니다.
벡터 DB(FAISS, Chroma, Weaviate, PostgreSQL+pgvector)에 저장.

4. 질문이 들어오면
질문 → 같은 임베딩 계산 → DB에서 가장 비슷한 조각 검색
검색 결과를 GPT 프롬프트에 넣어 “이 자료를 참고해 답변해”라고 전달.

# pip install chromadb
------------------------------------------------------------------------------------
api_key = "키 입력"


from openai import OpenAI
import chromadb

client = OpenAI(api_key=api_key)

# 1) Chroma DB 초기화
chroma_client = chromadb.Client()
collection = chroma_client.create_collection(name="company_docs")

# 2) 문서 임베딩 후 DB에 추가
docs = [
    "사내 복지 규정: 연차는 15일에서 시작…",
    "IT 보안 정책: 비밀번호는 12자 이상…",
]

for i, d in enumerate(docs):
    emb = client.embeddings.create(model="text-embedding-3-small", input=d).data[0].embedding
    collection.add(ids=[f"doc_{i}"], embeddings=[emb], documents=[d])

# 3) 검색 + GPT 답변
def ask(query):
    q_emb = client.embeddings.create(model="text-embedding-3-small", input=query).data[0].embedding
    results = collection.query(query_embeddings=[q_emb], n_results=2)

    context = "\n".join(results["documents"][0])
    messages = [
        {"role": "system", "content": "You are a helpful assistant for company policies."},
        {"role": "user", "content": f"문서 내용:\n{context}\n\n질문: {query}"}
    ]
    resp = client.chat.completions.create(model="gpt-3.5-turbo", messages=messages)
    return resp.choices[0].message.content

print(ask("연차는 며칠부터 시작해?"))

api_key = "키 입력"


from openai import OpenAI
import chromadb
import os

# 1) OpenAI & Chroma 초기화
client = OpenAI(api_key=api_key)

chroma_client = chromadb.Client()
collection = chroma_client.create_collection(name="company_docs")

# 2) 사내 문서 등록 (예제)
docs = [
    "사내 복지 규정: 연차는 15일에서 시작하며, 근속 연수에 따라 증가합니다.",
    "IT 보안 정책: 비밀번호는 12자 이상이며, 3개월마다 변경해야 합니다.",
    "재택근무 지침: 매주 최대 2회 재택근무가 가능합니다.",
]

# 문서 → 임베딩 → DB에 추가
for i, d in enumerate(docs):
    emb = client.embeddings.create(
        model="text-embedding-3-small",
        input=d
    ).data[0].embedding
    collection.add(ids=[f"doc_{i}"], embeddings=[emb], documents=[d])

# 3) 검색 + GPT 답변 함수
def ask(query: str) -> str:
    """질문을 받아 문서 검색 후 GPT로 답변 생성"""
    q_emb = client.embeddings.create(
        model="text-embedding-3-small",
        input=query
    ).data[0].embedding

    results = collection.query(query_embeddings=[q_emb], n_results=3)

    # 여러 문서를 연결
    context = "\n".join(sum(results["documents"], []))
    messages = [
        {"role": "system", "content": "You are a helpful assistant for company policies."},
        {"role": "user", "content": f"아래 문서를 참고해서 질문에 답하세요.\n\n문서:\n{context}\n\n질문: {query}"}
    ]

    resp = client.chat.completions.create(
        model="gpt-3.5-turbo",
        messages=messages,
        temperature=0.3
    )
    return resp.choices[0].message.content

# 4) 메인 루프 (콘솔 챗봇)
def main():
    print("=== 회사 문서 Q&A 챗봇 ===")
    print("종료하려면 'quit' 또는 'exit' 입력\n")

    while True:
        q = input("질문> ").strip()
        if q.lower() in ("quit", "exit"):
            print("챗봇을 종료합니다.")
            break

        try:
            answer = ask(q)
            print(f"답변> {answer}\n")
        except Exception as e:
            print(f"[오류] {e}\n")

if __name__ == "__main__":
    main()
